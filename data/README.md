# Sample Academic Data

The `academic_data.csv` file contains 500 synthetic academic records used to demonstrate the educational data platform.

## Dataset

| Column       | Description                  |
| ------------ | ---------------------------- |
| `student_id` | Synthetic student identifier |
| `course`     | Academic course              |
| `year`       | Academic year                |
| `month`      | Academic month               |
| `grade`      | Student grade                |
| `attendance` | Attendance percentage        |

The dataset is synthetic and does not represent real students, grades, attendance records, or institutional information.
